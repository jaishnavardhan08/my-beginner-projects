DHAROHAR — SEAMLESS WEBSITE

Open ONLY index.html.

The website now works as one seamless interface. Sign-in, Home, Plan Trip, Register Residence, Culture Quiz and About are displayed inside the same index.html shell, so clicking between them does not visibly open a new HTML page.

All supporting HTML files should remain in the same folder because index.html loads them internally.

For VS Code: open the folder and use Live Server on index.html if available. You can also double-click index.html.
